# 国际主义编辑设计

## 验证状态

这是 Visual Journalism 的候选 style，尚未通过本 skill 的完整样片验证。使用时必须明确标记为候选；只有代表性片段经过实际生成、内容质检并得到用户确认后，才能更新验证状态和经验规则。

## 风格定位

以国际主义平面设计的网格、留白、功能性排版和有限色彩组织现实影像、档案、地图与数据。画面应像一份经过严谨编辑的当代报道，而不是社交媒体拼贴模板、品牌广告或新闻演播室包装。视觉秩序来自信息层级和版面关系，不模仿任何单一媒体品牌。

## 稳定的视觉语言

- 采用清楚的模块化网格和不对称平衡。主体、标题、数字、图表与来源各有稳定版面区域；允许大面积留白，不用装饰填满空处。
- 基础色使用暖白、象牙白、浅灰或石墨黑。每支作品选择一种主强调色，必要时增加一种只承担第二语义的辅助强调色；同一颜色始终表达同一类别或关系。
- 现实影像使用自然光、真实空间、观察式距离和克制颗粒。裁切可以大胆，但不得把现场素材处理成商业广告或时尚大片。
- 图形以实心色块、细规则线、轴线、比例形状、裁切窗口和简洁标注为主。避免撕纸边、胶带、贴纸、手绘涂鸦和随机错位等 scrapbook 语言。
- 标题、数字和短标签可以成为构图主体。高密度正文、精确数字、单位、地图标签和来源必须由后期可控图形层完成；生成层只预留明确、稳定、对比足够的排版区域。
- 字体关系以功能性 grotesk 无衬线为主，可用克制的编辑型衬线字体承担引语、章节或历史层。字号、字重和位置建立层级，不依赖发光、立体挤压或夸张描边。
- 照片、地图和图表共享同一网格、边距与强调色，因此可以在不同媒介之间切换而不失去统一性。材质只保留轻微纸面、印刷或胶片颗粒，不覆盖数据和证据。
- 整体气质理性、清醒、精确而有编辑判断。高级感来自比例、留白、裁切和信息节奏，不来自“奢华”“电影感”等空泛修饰。

## 现实素材与证据

- 真实照片、视频、文件和网页保持来源身份，不生成伪页面或用风格处理掩盖关键上下文。
- 生成的现实感镜头只作为示意、重建或氛围层；存在被误认风险时在成片中披露。生成层不得冒充原始证据。
- 一条镜头只设一个主要阅读结论。需要比较时使用同一网格中的并列、基准线或比例关系，不堆叠多个争夺注意力的卡片。

## 地图与数据

- 地图使用平面色块、清楚边界、有限地名和单一当前高亮。地形或卫星底图只在空间问题需要时出现，不默认三维军事沙盘。
- 图表先建立基准，再显示比较或变化，最后停在当前结论。轴、单位、数字和来源由可控图形层绘制，运动不得改变数据比例。
- 大号数字必须附带足够的定义、时间范围和单位；不能为了版面冲击把预测写成已经发生的事实。

## 撰写图像 Prompt

1. 先确定镜头的信息职责和主要阅读结论，再选择真实影像、生成影像、档案、地图、图表或解释图形。
2. 写清网格关系、留白方向、主体裁切、基础色与唯一主强调色，不只写“瑞士风”“高级杂志”或媒体品牌名称。
3. 需要精确文字和数字时，把画面拆成生成底层与后期图形层；Prompt 只要求干净的排版区域和可控对比，不要求模型伪造整页信息。
4. 现实感画面写清地点类型、观察距离、自然光、主体行为和现场材质，并保留报道摄影的克制感。

## 撰写视频 Prompt

1. 使用网格重排、裁切窗口展开、色块滑入、基准线生长和图片边界移动揭示信息；所有运动都要改变阅读状态。
2. 标题、数字或图表进入后留出稳定阅读时间。摄影机和图形不要同时做竞争性大运动。
3. 现实影像默认使用克制推近、固定观察、横向跟随或有明确终点的平移；不用无意义环绕、快速变焦和持续漂浮。
4. 图表严格按“基准—变化—结论”推进；地图严格按“范围—位置—关系”推进。结束构图必须让当前结论一眼可读。
5. 不同媒介之间默认硬切，或通过相同网格位置、对象轮廓、方向和比例形成匹配切换；不使用故障、撕裂、融化和 HUD 擦除。

## 明确排除

- 撕纸、胶带、贴纸、报纸碎片、随机旋转和密集手绘标记构成的 Vox 式 scrapbook 拼贴。
- 复刻任何媒体的固定 Logo、专属品牌色、栏目包装或标志性版式。
- 企业宣传片式光滑摄影、镜头光晕、玻璃 HUD、发光网格和金融终端墙。
- 让生成模型自由绘制精确数字、复杂图表、地图边界、来源脚注或大段正文。
- 为了显得丰富而同时使用多套字体、多种强调色、多个装饰图标和持续运动。
- 只剩下排版形式，却没有证据、现实对象、机制、规模、后果或不确定性职责的空洞画面。
