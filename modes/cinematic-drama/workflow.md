# Cinematic Drama（剧情影像）

## 核心目标与当前状态

把已经确认的世界观、人物设定、剧本和指定情节，制作成由人物行动、对白与戏剧冲突驱动的 AI 电影、AI 漫剧、短剧或微电影。先建立全片统一的视觉与声音参考资产，再把剧情拆成最长 15 秒的独立视频片段，使用 Seedance 2.0 Pro 逐段生成并交付剪辑。

本 Mode 已吸收用户在多视图人物卡、场景参考、角色音色、15 秒五镜节奏和成本控制方面的实测经验，并已完成端到端作品验证。未经实测的平台映射仍不得声称为已经验证。

## 适用边界

- 作品依靠角色关系、人物行动、对白、冲突、悬念和后果推进，而不是依靠统一旁白解释概念或讲述个人经历。
- 适用于半写实 3D 动画电影、东方奇幻暗黑 3D、写实或其他用户确认的剧情影像风格；“AI 电影”“AI 漫剧”是媒介与发布形态，不限制题材。
- 默认假设世界观、人物设定和剧本已经完成。用户应提供或指向已确认材料，并明确本次要生产的具体情节。
- 本 Mode 不负责从零构建世界观或创作剧本。输入只有题材、灵感或一句故事概念时，明确指出缺少生产前提并停止；不得静默补写设定、剧情或对白。
- 可以把已确认剧本转成片段表、表演调度和生成 Prompt，但不得改变事件因果、角色动机、台词含义或结局。生产需要改写时先列出冲突并取得用户确认。

如果核心是知识解释，使用 [Animated Explainer](../animated-explainer/workflow.md)；如果核心是第一人称经历讲述，使用 [Storytime Animation](../storytime-animation/workflow.md)；如果结论依赖现实证据与资料核查，使用 [Visual Journalism](../visual-journalism/workflow.md)。

## 开始任务前必须读取

1. 资产规划、人物卡、换装、音色或场景参考：完整读取[视觉与声音参考资产指南](reference-development-guide.md)、[人物参考图指南](../../references/character-reference-image-guide.md)、当前选定 style；涉及音色时再读[音色参考与音频转换指南](../../references/voice-reference-guide.md)。
2. 拆分片段、设计镜头或编写视频 Prompt：完整读取[专属视频 Prompt 指南](video-prompt-guide.md)、当前选定 style、[共享视频生成 Prompt 指南](../../references/video-generation-prompt-guide.md)和[Seedance 2.0 官方提示词指南](../../references/official-seedance-2.0-prompt-guide.md)。
3. 创建、连接、生成、查询或下载媒体：完整读取用户选定的 CLI 工具文档并查询实时 schema。

## 固定模型与成本边界

- 正式剧情片段固定使用 **Seedance 2.0 Pro、720p**。每次创建或重生成节点都显式传入实际模型、`resolution=720p`、时长、画幅、声音开关和输入模式，不继承旧节点或平台默认值。
- 不主动选择、试用、比较或升级到 Seedance 2.5 Pro；不主动把正式片段升级到 1080p。模型推荐、平台新版本、旧节点设置或更高分辨率选项都不构成授权。
- 只有用户针对具体任务明确要求改变模型或分辨率，并在得知成本影响后再次确认，才允许偏离；否则停止，不静默升级、降级或切换。
- 每个正式片段最长 15 秒。片段时长是生成参数，不写进创作 Prompt。

## 核心交付物

进入视频生成前至少形成并确认以下内容：

1. **生产简报**：作品、目标情节、剧本来源、目标总时长、发布画幅、对白语言和已锁定内容。
2. **片段表**：片段编号、剧情职责、开场状态、结束状态、定稿对白、预计镜头数、出场角色和场景。
3. **角色资产表**：角色、服装版本、人物卡、出现片段、音色参考、确认状态和素材位置。
4. **场景资产表**：场景版本、空间结构、时间／天气／光线状态、出现片段、参考图和确认状态。
5. **连续性主体资产表**：武魂、召唤物、生物、关键道具等非人物主体的版本、稳定造型、出现片段、参考图和确认状态。
6. **片段 × 可辨识元素矩阵**：逐片段列出实际可见人物、场景、武魂、关键道具和实际说话角色音色，作为节点连接清单。
7. **style 锁**：用户确认的当前 Mode style 或自定义文字风格，以及所有人物卡、场景图、主体参考图和视频 Prompt 必须重复遵循的稳定视觉语言。
8. **逐片段 Prompt**：当前片段实际参考素材顺序、完整开场状态、镜头调度、声音和结束状态。
9. **生成记录**：平台、模型、分辨率、参数、素材映射、任务 ID、节点／项目 ID、终态、失败原因和下载路径。
10. **当前素材清单**：唯一列出当前获准进入正式生成的人物、服装、音色、场景、连续性主体和 Prompt 版本；历史候选与弃用资产不得继续出现在该清单中。
11. **项目级生成锁**：记录已经确认后必须跨片段持续执行的约束，例如是否允许字幕／屏幕文字、固定画风、角色名和阶位体系。

## 作品工作包与版本管理

- 每支新视频建立独立作品工作包，不与上一支作品共用可写目录。工作包至少保存人物单张候选、已确认多视图卡、音色参考、场景与连续性主体参考、全部片段 Prompt、生成记录和已下载视频。
- Prompt 与资产使用稳定版本号保存。V1、V2、V3 和失败版本都保留，不用“最终版”覆盖旧文件，也不把同一路径里的文件原地替换后继续沿用旧记录。
- 用户弃用的素材移入作品工作包内的可恢复 `archive/`，保留原 Prompt、生成来源、版本和弃用原因；不得删除后失去溯源，也不得让归档素材继续进入正式节点。
- `current-assets-manifest` 是生产输入的唯一权威清单。每次确认、换装、改名、换音色或归档后立即更新；创建节点前只按该清单解析本片段素材，不能靠目录中“看起来最新”的文件猜测。
- 上述作品媒体和私有平台标识属于宿主作品资产，不写入公开 skill 仓库；skill 只规定工作包结构、版本规则和质量门槛。

## 完整制作流程

1. **创建独立作品工作包。** 为本次新视频创建独立目录，初始化当前素材清单、项目级生成锁和可恢复归档目录；先登记用户已有素材，不从其他作品目录静默继承候选或废弃版本。
2. **确认生产前提。** 读取已确认世界观、人物设定和剧本，锁定本次情节、台词、目标时长与发布画幅。只做制作拆解，不创作缺失的世界观或剧本。
3. **拆成 15 秒片段。** 按完整事件、对白呼吸、动作因果和可剪辑切点拆分。普通快节奏片段以 5 镜为最常见起点；需要较长表演、复杂动作、压迫停顿或长镜头时使用 4 镜或 3 镜，不为凑数切镜。
4. **控制角色密度。** 单个场景或片段中需要稳定控制的主要角色通常不超过 4–5 人，并尽量更少。超出时优先把事件拆到多个片段、重新分配景别或把无固定身份者作为群演；任何会改变剧本含义的处理先征得用户确认。
5. **选择并锁定 style。** 只展示 Cinematic Drama 的内置 style 与自定义文字 style，等待用户选择。把稳定的媒介、写实程度、人物比例、材质、色彩、光影和渲染语言写成 style 锁；不得在后续资产或片段中静默换画风。
6. **建立人物参考。** 先把人物分为主角、配角和路人。主角与跨片段配角先分别生成 9:16 正面直立全身候选供用户抽卡；确认后再用实际候选图走图生图，制作 16:9 无文字多视图卡。主角默认建议完成多视图，重要配角按多角度镜头和服装控制需要制作，次要配角或快速样片可以只使用质量足够的已确认单张参考。路人不建立固定人物或声音资产。角色发生服装更换时建立单独服装版本；新版本必须以上一张已确认人物参考走图生图，不允许仅凭文字重新生成同一角色。
7. **建立角色音色。** 为每个有台词的固定角色选择已登记音色或生成独立音色候选，逐个听审确认后保存为本作品的角色声音锚点。没有台词的角色不为凑数生成音色；只在单个片段说话的一次性人物可以在 Prompt 内定义声音，不必建立跨片段锚点。
8. **建立场景参考。** 为反复出现、空间关系重要或需要跨片段保持一致的主要场景生成并确认场景参考图。不同服装、时间、天气或光线状态按指南建立明确版本，不让一张参考图承担互相冲突的状态。
9. **建立非人物连续性资产。** 为反复出现或承担关键动作的武魂、召唤物、生物、武器与关键道具生成并确认独立参考图；形态变化按版本管理，同一主体的新形态优先基于已确认参考走图生图。
10. **建立片段素材矩阵。** 逐片段列出实际可见人物、场景、武魂、关键道具和实际说话角色音色。每个视频节点连接该片段所需的全部且仅有的连续性资产，不遗漏同场配角，也不连接未出现或没有说话角色的冗余音色。
11. **执行生成前冲突核对。** 逐项对照定稿剧本、资产表、当前素材清单和实际打开检查过的参考图片／音频。用户确认或提供的参考媒体优先定义视觉与声音身份；同步改写仍与它冲突的文字描述。冲突会改变剧情机制或角色含义时停止并请用户裁决，不把互相矛盾的素材和 Prompt 一起提交。
12. **编写并保存全部 Prompt。** 按片段表和专属指南逐个编写。每个 15 秒片段都是独立请求，必须自包含地定义实际参考职责、开场状态、角色、场景、声音、style 锁、镜头顺序和结束状态；每次修改创建新版本，不覆盖旧 Prompt。
13. **先生成代表性片段。** 默认选择片段 1；如果片段 1 不包含主要角色、主要场景或典型对白，则选择最能检验人物、场景、音色和风格一致性的片段。只生成该片段并交给用户确认，不在未确认时批量消耗成本。
14. **批量生成其余片段。** 代表性片段通过后，对照素材矩阵、当前素材清单和项目级生成锁核对每个节点，只提交已经确认且可追踪的片段。正式视频始终使用 Seedance 2.0 Pro、720p。
15. **跟踪并交付。** 确认所有任务成功终态和资源完整性。每个成功片段在资源 URL 可用后立即按补零编号下载到作品 `video/` 目录，返回本地文件路径，并在宿主支持时直接展示可播放视频；不得只交付远程节点、任务 ID 或 URL。任务失败且没有资源 URL 时明确说明无文件可下载。默认交给用户在剪辑工具中排序、拼接、修剪废帧和片尾毛刺；只有用户明确要求时才自动拼接。

## 进入生成前的质量门槛

以下任一情况存在时停止生成并报告：

- 世界观、人物设定、剧本或本次目标情节缺失，或仍存在会改变制作方案的冲突。
- 定稿对白、事件顺序或片段起止状态尚未锁定。
- 当前素材清单缺失、仍引用归档素材，或 Prompt／剧本描述与实际参考媒体互相冲突。
- 已确认的项目级生成锁没有落实到当前片段；例如项目已锁定无字幕，当前 Prompt 却仍要求屏幕文字。
- style 尚未确认，或人物卡、场景图和视频 Prompt 使用了互相冲突的视觉语言。
- 任一主角或跨片段配角缺少已确认的当前服装版本人物参考；计划要求三视图的角色尚未完成三视图；换装卡不是基于已确认人物参考的图生图结果。
- 任一说话角色缺少已确认音色，或片段中的人物、台词与音频职责无法一一对应。
- 任一连续性关键场景缺少已确认场景参考，或场景版本与片段的时间、天气、陈设不匹配。
- 任一反复出现或承担关键动作的武魂、召唤物、生物或关键道具缺少已确认参考图，或当前形态版本与片段不匹配。
- 尚未完成片段素材矩阵，或当前片段遗漏实际出现的固定人物、场景、武魂、关键道具或说话角色音色参考。
- 单片段主要角色过多，导致参考职责、镜头调度或对白无法在 15 秒内清楚完成。
- Prompt 没有完整定义当前片段的开场状态，或使用“承接上一片段”等跨请求省略写法。
- 模型不是 Seedance 2.0 Pro，正式分辨率不是 720p，或参数依赖旧节点与平台默认值。
- 代表性片段尚未得到用户确认，却准备批量生成其余片段。

失败时保留具体资产版本、Prompt、参数、任务 ID、终态和错误日志。修正真实原因后重新执行，不靠换模型、升分辨率或改写剧情掩盖问题。
