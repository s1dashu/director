# 黏土微缩定格寓言

## 当前状态

本 style 是 Clay Stop-Motion Mode 的首轮候选视觉语言，尚待第一支完整样片验证。它定义跨作品稳定的手工媒介与运动原则，不规定固定角色、森林布景、配色、镜头顺序或故事寓意。

## 稳定的视觉语言

- 使用真实手工制作的黏土偶和实体微缩布景摄影观感。保留指纹、压痕、塑形刀痕、部件接缝、轻微不对称和手工切边，但角色轮廓与身份特征保持稳定。
- 不把整个世界统一做成一种光滑橡皮泥。角色裸露表面可以是哑光黏土；服装、毛发、屋顶、书页、树皮和金属小物分别使用毛毡、织物、纸浆、纸张、木片、软木、细线或带手工痕迹的仿金属材料。
- 角色使用适合逐格表演的清楚轮廓、可读手势和略微夸张的关键姿态。可爱程度由受众与故事决定，不默认大眼幼儿化，也不把反派做成身份刻板印象。
- 布景具有可感知的微缩尺度：材料纤维、手工边缘、真实接触阴影、浅景深与尺寸略不完美的道具共同建立尺度感。
- 使用真实棚拍式主光、补光与背景层次。光线可以温暖、阴郁、清晨或夜晚，但必须来自布景中可理解的方向，并在同一连续空间保持一致。
- 色彩由故事情绪和角色关系决定，优先使用受控的有限色板与清楚的主体—背景分离；不固定为低饱和棕色、糖果色或单一童话配色。
- 画面保留实体摄影的光学质感与适度景深，避免无瑕数字 3D、光滑塑料玩具、写实真人皮肤、无限干净的程序化表面或漂浮的纯数字特效。

## 撰写图像 Prompt

1. 先写画面的叙事职责、角色姿态、道具状态、布景结构、视角、景别和光线，再为每类元素指定合适的手作材料。
2. 角色参考图默认是一张只出现一个角色、无遮挡、全身清楚可见的黏土偶定妆照，锁定轮廓、体型、五官塑形、服装材料、配色、接缝和稳定手作痕迹。背景简洁但仍使用真实棚拍光与接触阴影。
3. 反复出现的布景参考图应无人物、无文字，完整展示空间结构、入口、固定陈设、材质和基础光位；它不预设后续视频镜头构图。
4. 关键道具参考图只展示一个物件及其指定状态，写清材料、尺度线索、开合结构与可被角色抓握或推动的位置。
5. 不用“黏土风”单一标签代替材料设计，也不为建立风格生成抽象 moodboard。每张图都必须是当前作品实际需要的角色、布景或道具资产。

## 撰写视频 Prompt

1. 用预备、接触、受力、结果和停住等清楚关键姿态组织动作。逐格质感来自可读的位置增量、略有阶梯感的加减速和有意义的短暂停顿，不来自全局随机抖动。
2. 让不同材料按各自性质反馈：黏土轻微压缩并留下压痕，毛毡弯折，纸张起皱，织物形成褶皱，木片保持较硬。只在接触点发生必要形变，不让角色持续融化。
3. 优先让角色触碰、搬运、折叠、搭建、拆开、交换或修复实体道具，使材料反应推进故事因果；不为展示风格反复揉捏无关物件。
4. 摄影机遵循真实微缩摄影逻辑，可以固定、短距离横移、低位跟随、俯拍、微距推拉或逐格轨道移动。每次写清起点、路径、参照物和停止位置，不给每段套用相同桌面推镜或环绕。
5. 相邻镜头默认硬切。保持角色偶身份、材料体系、布景尺度、光位和逐格表演语言；只有连续动作本身承担叙事职责时才使用不中断调度。
