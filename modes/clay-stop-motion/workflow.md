# Clay Stop-Motion（黏土定格寓言）

## 当前状态与核心目标

本 Mode 用真实手工黏土偶、微缩布景和逐格表演的视觉语言，创作由角色选择、错误、后果与改变驱动的寓言、品格教育故事和具有明确启发意义的短篇叙事。它可以从用户提供的道德命题、故事梗概、传统寓言或已定稿故事出发，完成故事开发、旁白与对白、角色和布景规划、片段拆分、Seedance 视频 Prompt、生成跟踪与交付。

本 Mode 已建立首轮候选工作流，尚未完成端到端样片验证。首次实作必须保留故事修改、参考资产、Prompt、模型参数、失败任务、重生成原因和用户反馈；在样片获得用户确认前，不把候选节奏、资产组合或 Prompt 方法标记为已验证。

## Mode 边界

在以下情况选择本 Mode：

- 视频的核心是一则通过具体角色、行动和后果成立的寓言或教育性故事。
- “要教会观众什么”需要被转化为角色在微缩世界中的选择，而不是由旁白直接讲解概念。
- 黏土偶、手作布景、实体道具与逐格动作不仅是画风，还承担故事表演和因果表达。

以下情况使用其他 Mode：

- 第一人称亲历故事及讲述者回看使用 [Storytime Animation](../storytime-animation/workflow.md)。
- 核心目标是解释概念、理论、历史或知识，而故事只是例子，使用 [Animated Explainer](../animated-explainer/workflow.md)。
- 已有完整世界观、人物和剧本，作品主要依靠对白、冲突与电影式表演推进，使用 [Cinematic Drama](../cinematic-drama/workflow.md)。
- 结论依赖现实证据、数据、档案或时效性资料，使用 [Visual Journalism](../visual-journalism/workflow.md)。

不要仅因用户说“黏土风”就自动选择本 Mode。先判断内容是否真的由寓言式事件推进；纯知识解说不能借一层黏土材质伪装成寓言，普通剧情也不能因为使用黏土偶就跳过已经确认的剧本生产流程。

## 开始任务前必须读取

1. 构思、改编、写作或拆分故事：完整读取[寓言故事与声音写作指南](story-and-narration-guide.md)。
2. 规划人物、动物角色或拟人对象：完整读取[人物参考图指南](../../references/character-reference-image-guide.md)和用户选定的当前 Mode style。
3. 规划反复出现的微缩布景或关键道具：使用本文件的“参考资产与连续性”规则；不得用抽象画风参考图代替 style。
4. 编写视频 Prompt：完整读取[专属视频 Prompt 指南](video-prompt-guide.md)、当前 style、[共享视频生成 Prompt 指南](../../references/video-generation-prompt-guide.md)、[Seedance 2.0 官方提示词指南](../../references/official-seedance-2.0-prompt-guide.md)；出现循环动作、重复运镜或切镜僵硬时再读[社区导演与连续性笔记](../../references/community-directing-notes.md)。
5. 选择或建立旁白音色：完整读取[内置音色库](../../references/reference-asset-library.md)和[音色参考与音频转换指南](../../references/voice-reference-guide.md)。
6. 创建、连接、生成、查询或下载媒体：完整读取用户选定的 CLI 工具文档并查询实时 schema。

## 故事原则

### 让教训从因果中出现

- 先用一句话写清：谁想得到什么，因为哪种选择走偏，付出什么可见代价，最后怎样改变。
- 道德命题必须能被一个具体选择检验。例如“诚实”要落到角色是否隐瞒、隐瞒造成什么后果以及坦白后怎样修复，不能只让旁白反复赞美诚实。
- 主角不能只是被动受罚。至少安排一次能够暴露性格的主动选择，以及一次在看见后果后采取的新行动。
- 结尾优先用动作、关系或环境状态回应开头。可以保留一句克制的点题旁白，但不以长篇训话替代故事收束。

### 寓言不等于幼稚

- 先确认受众年龄、文化语境、情绪强度和希望留下的思考，再决定角色可爱程度、后果强度与语言难度。
- 动物、植物和物件可以拟人化，但它们的身体结构、能力边界和世界规则要前后一致。不能为推动剧情临时获得未建立的能力。
- 不用羞辱、恐吓、身份刻板印象、贫穷或残障作为廉价惩罚。错误必须与角色的选择形成可理解的因果，而不是由作者随意降下报应。
- 改编传统寓言、宗教故事或明确教义时，先确认来源、允许改编的范围和不可改变的核心含义；无法核实的原句不用引号冒充原文。

## 核心交付物

进入生成前至少形成并确认：

1. **创作简报**：受众、目标时长、语言、情绪、道德命题、来源与改编边界。
2. **故事命题**：主角目标、错误选择、升级、直接后果、新选择与结尾回声。
3. **定稿故事稿**：旁白、对白、重要声音及片段拆分；确认后保存为 `故事稿.md`。
4. **角色资产表**：角色标签、物种或形体、稳定特征、材料、服装、出现片段、参考图和确认状态。
5. **布景与道具连续性表**：重复布景的空间结构、入口、固定物、光源方向；关键道具的外观、持有者、位置、状态变化和参考状态。
6. **style 锁**：已确认的内置或自定义黏土定格文字 style。
7. **逐片段 Prompt**：当前素材真实顺序、声音正文、开场状态、逐镜动作、摄影、定格运动和结束状态。
8. **生成记录**：平台、模型、参数、素材映射、任务与节点 ID、终态、失败原因和下载路径。

## 参考资产与连续性

- 通读完整故事后再确定关键角色数量。跨镜头或跨片段需要稳定辨认的角色分别建立单人物参考图；一次性背景角色不建立独立参考。
- 角色参考默认使用无遮挡、全身可见的单个黏土偶，锁定轮廓、五官塑形、体型、服装材料、配色、接缝与手作痕迹。只有确有转身、背部结构、换装或特殊配件需求时才补充视图。
- 对反复出现且空间关系会影响行动的主要微缩布景，可以建立无人物、无文字的布景参考图；它只负责空间结构、固定陈设、材料和基础光位，不负责镜头构图或动作。
- 对推动因果并跨片段改变状态的关键道具，可以建立独立道具参考图并记录完好、损坏、打开、空置等版本。普通一次性道具直接用文字定义。
- 不生成抽象“画风参考图”。媒介、材料、色彩和运动语言始终由当前 style 的文字规则锁定。
- 每个视频节点只连接当前片段真实需要的角色、布景、道具和音频。Prompt 按真实连接顺序逐项声明职责，不能让布景图复制其中偶然出现的人物，也不能让角色图决定背景构图。
- 维护跨片段状态账本：角色服装与污损、道具持有者与破损程度、布景中被移动或移除的物件、时间与光线。新片段虽然是独立请求，也必须完整重述自己的开场事实。

## 片段与声音结构

- 每个片段最长 15 秒。候选起点为 3–5 镜，约 4 镜通常能给逐格动作、短暂停顿和材料反馈留下空间；镜头数由事件和表演决定，不机械固定。
- 旁白驱动片段应让相同时长段落的朗读量接近。中文可先以约 50–58 个实际朗读汉字作为首轮测试范围，英文可先以约 26–30 个实际朗读单词作为首轮测试范围；复杂动作、角色对白、喜剧停顿或结尾留白需要更多时间时应进一步缩短。该范围是待样片验证的候选值，不是已验证硬标准。
- 旁白、对白和画面必须分工：旁白负责必要的时间跳跃、视角或无法从动作直接获知的信息；角色选择、冲突和后果尽量让画面自己完成。
- 默认使用一位稳定讲述者与少量角色短对白。若作品主要由多角色连续对白推进，应重新判断是否更适合 Cinematic Drama。
- 正式生成前仍由用户选择已有音色或通过片段 1 新建音色，不为“寓言感”静默指定老人、儿童或温柔女声。
- 背景音乐、环境声、拟音和对白策略由当前作品确认。黏土触碰、布料、木片、纸张和脚步拟音应跟随动作发生；不把持续的塑料摩擦声或每步相同的“咔哒声”当作定格风格标志。

## 完整制作流程

1. **确认命题与边界。** 明确受众、目标时长、希望观众理解的命题、故事来源、改编权限和不希望采用的训诫方式。
2. **建立故事因果。** 按写作指南形成主角目标、诱因或误判、升级、直接后果、新选择与结尾回声；先确认故事骨架，再写全文。
3. **写作并拆分。** 完成故事稿，标明旁白、说话人和必要声音；按完整事件、动作表演和可剪辑终点拆成最长 15 秒的片段。向用户展示并确认后保存为 `故事稿.md`。
4. **选择并锁定 style。** 只展示本 Mode 的[黏土微缩定格寓言](styles/handcrafted-clay-fable-stop-motion.md)候选 style 与用户自定义的黏土定格文字 style，明确候选状态并等待选择。
5. **规划并确认资产。** 建立角色、重复布景和关键道具清单；生成最少而充分的参考，逐项获得用户确认，并完成出现片段与状态映射。
6. **制作片段表。** 为每段写清故事职责、开场状态、可见选择、后果、结尾状态、声音正文、角色、布景、道具和预计镜头数。
7. **逐片段编写并保存 Prompt。** 按专属指南和 Seedance 规则，自包含地声明素材职责、声音、style 锁、逐格动作、相机和结束状态；每段保存为独立 Markdown 文件。
8. **先生成代表性片段。** 优先选择同时包含主要角色、关键道具接触、典型布景、旁白或对白和明确后果的片段；若片段 1 已具代表性则使用片段 1。只生成该片段并交给用户确认，不提前批量消耗成本。
9. **锁定音色与视觉连续性。** 按音色指南确认已有音色或从片段 1 建立锚点；记录通过样片中的角色比例、材料、动作节奏、布景尺度和声音表现，修正 Prompt 根因后再继续。
10. **生成并交付其余片段。** 核对每个节点真实素材和参数后生成；成功返回资源 URL 时立即下载到作品 `video/` 目录，使用补零片段编号，并保留完整任务记录。
11. **提示剪辑收尾。** 默认由用户在剪辑工具中排序、硬切、修剪废帧和片尾毛刺，检查旁白节奏、拟音落点和结尾停顿；只有用户明确要求时才自动拼接。

## 进入生成前的质量门槛

以下任一情况存在时停止生成并报告：

- 无法用一句话说清主角想要什么、哪次选择使局面恶化、代价是什么以及最后采取了什么新行动。
- 道德命题只能依靠结尾训话成立，删除点题句后故事本身看不出相关因果。
- 故事借羞辱、身份刻板印象或无关灾祸惩罚角色，错误与后果之间没有可理解联系。
- 来源、改编权限或必须保留的教义含义尚未确认，却准备把改编包装成原故事。
- 角色、布景或关键道具的状态账本互相冲突，或任一必须稳定识别的角色缺少已确认参考。
- Prompt 只写“黏土风、定格感”，没有明确材料、逐格关键姿态、接触反馈、摄影机起止和镜头结束状态。
- 所有动作都被要求持续抖动、抽动或橡皮式变形，定格质感没有服务动作和故事。
- 代表性片段尚未得到用户确认，却准备批量生成其余片段。
