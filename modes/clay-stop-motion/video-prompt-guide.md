# Clay Stop-Motion 视频 Prompt 指南

## 目标

把已确认的寓言故事、角色偶、微缩布景、关键道具和声音稿，写成 Seedance 2.0 能在单个最长 15 秒片段中执行的黏土定格动画摄影方案。Prompt 必须同时控制故事因果和定格媒介：角色做什么选择、动作如何逐格推进、实体材料怎样受力、摄影机从哪里观察、镜头以什么新状态结束。

只写“黏土风、定格动画、可爱、电影感”不会形成可控的定格结果。把模型当作一支不知道上下文的微缩动画摄制组；未在当前请求中声明的角色身份、布景状态、道具位置、声音和动作阶段，都不能指望它从其他片段自行补全。

同时遵循当前 style、[共享视频生成 Prompt 指南](../../references/video-generation-prompt-guide.md)、[Seedance 2.0 官方提示词指南](../../references/official-seedance-2.0-prompt-guide.md)和目标 CLI 的实时 schema。时长、比例、分辨率、声音开关、数量和输入模式只通过 CLI 参数传递，不写进创作 Prompt。

## 写作前准备

为当前片段确认：

1. 本段唯一故事变化，以及开场与结尾的可见状态。
2. 定稿旁白、对白、说话人、情绪转折和拟音职责。
3. 当前节点真实连接的角色、布景、道具和音频参考顺序。
4. 每个角色偶的稳定标签、材料、服装、起始姿态与所在位置。
5. 关键道具在片段开始时的持有者、方向、开合、完好程度和位置。
6. 重复布景的固定结构、入口、主要陈设与光源方向。
7. 当前片段需要强调的定格表演：关键姿态、短暂停顿、接触、受力、材料反馈和落点。

故事稿未定稿、资产状态互相冲突或素材真实顺序不明时，不写最终 Prompt。

## Prompt 固定顺序

按以下顺序组织，没有对应素材时跳过：

1. 逐项声明参考素材职责，并定义固定角色标签。
2. 写明旁白与对白语言、音色来源、表达方式和准确正文。
3. 声明当前 style 锁与片段的具体微缩布景、材料、尺度、色彩和光线。
4. 写清开场时角色、道具和环境的完整状态。
5. 按事件顺序写 `镜头 1、镜头 2……`。
6. 只写当前作品已确认的背景音乐、拟音、字幕或画内文字要求。

候选结构：

```markdown
图片1为“灰兔邮差”的单人物黏土偶参考图，只参考灰兔邮差的头身比例、长耳轮廓、蓝色毛毡背心、黄铜纽扣和手作黏土表面。图片2为树根邮局的无人物微缩布景参考，只参考弧形木门、左侧分信桌、右侧麻绳架、纸浆墙面和暖色窗光。音频1仅用于参考讲述者音色，本片段准确声音内容只以提示词中的正文为准。

讲述者使用中文，以音频1的音色，用克制而温暖的故事语气完整说出{定稿旁白}。灰兔邮差说出{定稿对白}。全片声音策略以当前作品确认为准。

所有镜头采用{当前 style 锁}。本片段是可感知微缩尺度的真实手工黏土偶定格摄影；角色、道具和布景分别保留已定义的黏土、毛毡、纸张、木片与织物材质，不统一变成光滑塑料。

开场状态：灰兔邮差站在分信桌左侧，身体朝向画面右侧；封蜡完好的红色信封压在右手掌下；麻绳架保持空置，暖色主光从画面左后方窗户照入。

镜头 1：
[具体微缩场景与机位；角色或道具的起始姿态；按顺序发生的逐格动作、接触、受力与材料反馈；摄影机路径；结束姿态、构图与声音落点。]
```

示例只说明结构，不是固定角色、布景、镜头或声音模板。实际 Prompt 按当前故事重新设计。提交模型前剥离文档中的 `片段 N`、字数、审稿说明和执行参数。

## 参考素材职责

- 每张角色参考只负责该角色的身份、轮廓、比例、服装、材料和稳定手作特征。用 2–3 个最有区分度的静态特征定义唯一标签，并在全部镜头中持续使用该标签。
- 布景参考只负责空间结构、固定陈设、材质和基础光位，不自动决定当前镜头构图，也不把图中偶然出现的角色或道具复制进视频。
- 道具参考只负责外形、材料、尺度和指定状态。若当前片段要让它破裂、打开、变脏或被修复，在动作段落写清从哪个状态变到哪个状态。
- 音频只承担已声明的音色职责。当前旁白和对白只来自 Prompt 中的准确正文，不复述样本原话。
- 每个节点只连接当前片段真正需要的素材。若平台要求有效视觉输入，连接当前故事中真实需要的角色、布景或道具，不接入无关图片通过校验。

## 把“定格感”写成可见动作

### 关键姿态与节奏

- 把动作拆成少量清楚的关键姿态：预备、接触、受力、结果、停住。写出每个阶段的身体部位、方向、幅度和结束位置，而不是笼统要求“做出定格动画动作”。
- 允许在重要决定、意外结果或喜剧落点前后出现短暂停顿，让观众读懂姿态。停顿必须落在明确姿势上，不让人物无故冻结。
- 逐格质感来自可读的位置增量、略有阶梯感的加速减速和人工调整痕迹，不来自全程随机抖动。静止的布景、摄影机和未参与动作的道具应保持稳定。
- 快速动作可以用更大的姿态间隔和短促落点；谨慎、犹豫或负重动作使用更小的位移、更多准备姿态和更长的受力过程。不要给所有角色同一种顿挫节奏。

### 材料、重量与接触

- 写清接触发生在哪里：哪只手、哪一面道具、从哪个方向施力、物体沿什么路径移动、停止在哪里。
- 黏土在挤压、握持、碰撞时可以出现轻微压痕、扁缩或回弹；毛毡弯折、纸张起皱、木片保持较硬、织物产生褶皱。材料反馈必须符合对象，不让整个人物像橡皮一样持续融化。
- 重物先出现身体后倾、脚底受力或道具轻微迟滞，再发生位移；轻物可以迅速翻动或弹起。动作结束后留下可见结果，例如压痕、散落碎屑、移动后的空位或改变的姿势。
- 指纹、塑形痕迹和接缝是稳定材质特征，不要求它们在每一帧剧烈跳动或重新排列。

## 镜头设计与摄影

- 15 秒候选起点为 3–5 镜，约 4 镜适合多数寓言片段。一个复杂道具动作、情绪停顿或对白表演需要更多时间时减少镜头；紧凑的无对白蒙太奇才考虑增加。
- 每镜必须推动一次选择、阻碍、发现、后果或修复。不能只换景别重复角色已经完成的动作。
- 相邻镜头默认硬切。连续动作确实需要保持空间关系时才使用不中断调度；不写融化、变形或材料接力转场来炫耀黏土媒介。
- 摄影机使用真实微缩摄影逻辑。写清机位相对布景和角色的位置、高度、朝向、景别、移动路径与终点；固定三脚架、低位跟随、短距离横移、俯拍或受控微距推拉都可以按叙事需要使用。
- 运镜本身不应随机跳格或手持抖动。需要逐格移动摄影机时，说明它沿轨道分步移动并在结束位置稳定停住；不让每镜都使用同一种桌面推镜或绕拍。
- 景深要帮助阅读微缩尺度，但不能让关键动作或道具落在无法辨认的模糊区。焦点转移时写清从哪个对象移到哪个对象以及何时停住。
- 每镜写到明确终点：角色姿态、视线、道具位置与状态、布景变化、光线、焦点、结束景别和声音落点。下一镜若继续同一事件，只承接已完成状态，不重新表演上一镜动作。

## 声音与画面配合

- 旁白和对白分别写明说话人、音色来源、语速、情绪与准确正文。对白角色需要可读口型时写清面部朝向和反应时间；无需说话的角色不做无意义口型。
- 拟音跟随可见接触点出现，例如毛毡摩擦、纸张折叠、木片碰撞、黏土脚步和陶制小物滚动。使用 `<拟音描述>` 时只写当前动作真实需要的声音。
- 不让旁白、多人对白、复杂动作、密集拟音和大幅运镜同时争夺片段时长。声音过满时优先删减重复旁白或拆分片段。
- 背景音乐不是黏土定格的默认组成。只按用户确认的作品声音策略写入，不擅自加入童话音乐、钟琴或温馨弦乐。

## Seedance 常见失败与根因检查

### 画面变成光滑 CGI

先检查是否只写了“黏土风”，或把所有表面都描述成统一光滑材质。补足真实微缩摄影、对象各自材料、手作边缘、接触阴影、指纹与塑形痕迹；不要靠堆叠更多“高质量 3D”词补救。

### 全画面持续抖动

检查是否把“定格感”误写成每帧抖动、镜头摇晃或所有物体跳动。改为具体关键姿态、阶梯式位移和有意义的短暂停顿，并明确摄影机、布景和未参与动作的物体保持稳定。

### 角色像橡皮一样融化

检查是否无差别要求揉捏、拉伸、变形。只在真实受力点写轻微压缩或压痕，让角色骨架、轮廓、服装和身份特征在动作后保持稳定。

### 动作循环或状态重置

检查上一镜是否已经完成推门、举起、回头或放下，而下一镜又从动作之前开始。为每镜记录结束状态；下一镜从新信息或后果继续，只有有意重复时才明确写出新的触发原因。

### 寓意变成漂浮符号

检查是否用发光爱心、天平、文字牌或无来源的象征物代替角色选择。把命题重新落实为角色、实体道具、空间限制和可见后果；象征只能作为事件中的次要细节。

## 落盘与提交检查

每个片段单独保存为 Markdown 文件，至少记录 Mode、作品、片段编号、style、故事职责、角色／布景／道具／音频映射、开场状态、定稿声音内容、完整 Prompt 和执行约束。文件编号、故事稿片段编号、视频节点与下载文件保持一致。

提交前确认：

- 素材编号与当前节点真实连接顺序一致，每份参考只承担已声明职责。
- 当前片段自包含地写清角色、布景、道具与声音的开场状态，不依赖“承接上一段”等省略写法。
- 旁白与对白逐字匹配定稿，只出现一次并放在 `{}` 中；没有把管理标签或参数提交给模型。
- 每镜都推动故事变化，并具有起始构图、关键姿态、接触与受力、可见后果、摄影机路径和结束状态。
- 定格质感来自逐格姿态、材料和真实微缩摄影，而非全局抖动、低质跳帧或橡皮式变形。
- 角色轮廓、材料、服装和手作特征稳定；布景方向与道具状态符合连续性账本。
- 镜头数、声音量、动作和停顿能够在片段时长内自然完成。
- 只写入用户确认的背景音乐、字幕、Logo、画内文字和其他额外约束。
